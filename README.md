# Divine Dwelling Invites

Interactive Housewarming & Thanksgiving service digital invitation web application.

## Development

Install dependencies and start the dev server:

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Tech Stack

- TanStack Start & TanStack Router
- React 19
- Tailwind CSS v4 & Lucide Icons
- TypeScript & Vite
